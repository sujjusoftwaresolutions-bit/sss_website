# 🛡️ Enterprise High-End Security Deployment Guide
## SUJJU Software Solutions (Namecheap + Cloudflare Security Setup)

This guide details how to configure **Enterprise-Grade Security** for your custom domain on **Namecheap** using **Cloudflare WAF (Web Application Firewall)**, without relying on Netlify.

---

## 🔒 Security Architecture Overview

1. **Cloudflare Security Edge (WAF & Anti-DDoS)**: Intercepts all web traffic, blocks malicious botnets, filters SQLi/XSS attacks, and provides free SSL/TLS encryption.
2. **Namecheap Hosting (Apache + Node.js)**: Runs frontend and backend under protected `.htaccess` rules, strict CORS, rate limiters, and NoSQL injection filters.
3. **MongoDB Atlas (Database Security)**: TLS encrypted connection strings with IP whitelist restrictions.

---

## ⚡ STEP 1: Connect Namecheap Domain to Cloudflare (Free Layer 7 Anti-DDoS)

Using Cloudflare in front of Namecheap hides your server IP address from hackers and automatically mitigates DDoS attacks.

1. **Sign up / Sign in to Cloudflare**:
   - Go to [Cloudflare.com](https://www.cloudflare.com/) and create a free account.
2. **Add Your Domain**:
   - Click **+ Add a Site** -> Enter your domain (e.g., `sujjusoftware.com`).
   - Select the **Free** plan ($0/month).
3. **Copy Cloudflare Nameservers**:
   - Cloudflare will scan your DNS records and give you two nameservers (e.g., `aria.ns.cloudflare.com`, `bob.ns.cloudflare.com`).
4. **Update Nameservers in Namecheap**:
   - Log into **Namecheap Dashboard** -> **Domain List** -> Click **Manage** next to your domain.
   - Under **Nameservers**, change from *Namecheap BasicDNS* to **Custom DNS**.
   - Paste the 2 Cloudflare Nameservers and click the **Green Checkmark** to save.

## 🔒 STEP 2: Configure Cloudflare High-End Security Settings

Once your domain is active on Cloudflare, enable these settings in your Cloudflare Dashboard:

### 2.1 SSL/TLS Encryption
- Navigation: **SSL/TLS** -> **Overview**
- Mode: Set to **Full (Strict)** (Ensures encrypted connection between Cloudflare and Namecheap cPanel).

### 2.2 Edge Certificates & HTTPS Rules
- Navigation: **SSL/TLS** -> **Edge Certificates**
  - **Always Use HTTPS**: Turn `ON`.
  - **HTTP Strict Transport Security (HSTS)**: Enable (max-age 12-months, include subdomains, preload).
  - **Minimum TLS Version**: Set to `TLS 1.2` (blocks insecure legacy connections).
  - **Automatic HTTPS Rewrites**: Turn `ON`.

### 2.3 Web Application Firewall (WAF) & Bot Protection
- Navigation: **Security** -> **Bots**
  - **Bot Fight Mode**: Turn `ON` (automatically blocks known malicious scrapers and attack bots).
- Navigation: **Security** -> **WAF** -> **Managed Rules**
  - Enable OWASP Top 10 Security Ruleset.

### 2.4 DNSSEC (Prevent DNS Hijacking)
- Navigation: **DNS** -> **Settings** -> **Enable DNSSEC**
- Copy the DS Record generated by Cloudflare and paste it into Namecheap under **Domain** -> **Advanced DNS** -> **DNSSEC**.

## 🛠️ STEP 3: Backend Security Verification

Your Node.js API server (`backend/server.js`) has been pre-configured with:

1. **NoSQL Query Injection Filter (`express-mongo-sanitize`)**: Blocks attempts to bypass authentication via `$gt` or `$ne` operators.
2. **HTTP Parameter Pollution Defense (`hpp`)**: Blocks parameter flooding attacks.
3. **Helmet HTTP Headers**: Enforces CSP, HSTS, X-Content-Type-Options, X-Frame-Options (DENY), and disables `x-powered-by`.
4. **Brute-Force Rate Limiting**:
   - General API: Max 150 requests per 15 mins.
   - Auth Endpoints (`/api/auth/login`, `/api/auth/register`): Max 5 attempts per 15 mins.
   - Contact Form (`/api/contact`): Max 10 messages per hour.
5. **Strict CORS Whitelist**: Only allows your exact production domain and local dev server (All Netlify origins have been removed).

---

## 🎨 STEP 4: Frontend Apache Security Verification (`.htaccess`)

Your frontend static distribution on Namecheap (`public_html`) is protected by `.htaccess` rules:

1. **Directory Indexing Locked**: `Options -Indexes` prevents visitors from seeing raw file listings.
2. **Sensitive Files Denied**: Access to `.env`, `.git`, `package.json`, and `.htaccess` is blocked with HTTP 403 Forbidden.
3. **URL Parameter Injection Guard**: Rejects URLs containing SQL/XSS exploit strings (`<script>`, `eval(`, `SELECT`, `UNION`, `../`).
4. **Strict HTTP Security Headers**: HSTS, Referrer-Policy, X-Frame-Options SAMEORIGIN, and Permissions-Policy.

## 🗄️ STEP 5: MongoDB Atlas Hardening

1. In MongoDB Atlas, go to **Database Access**:
   - Use a strong 24+ character password for your database user.
2. Go to **Network Access**:
   - Whitelist your Namecheap Server IP address (found in your cPanel sidebar) or restrict access strictly to trusted backend instances.
3. Keep your `MONGODB_URI` secret in cPanel Node.js Application Environment Variables (Never commit `.env` to Git).
